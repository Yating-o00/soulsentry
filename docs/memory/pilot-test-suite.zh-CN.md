# 心栈中国版 · 记忆 Pilot 测试集

**版本：memory-pilot-v2。** 四段合成对话、19 个检索探针，其中 12 个同时评测实时回答，包含 4 个规划请求。其余 7 个仅测检索。这里列出完整输入与期望；可执行定义见 [pilot.js](../../backend/scripts/memory-eval/pilot.js)。

## 对话与记忆状态

同一行的两个批次按时间顺序输入。**显式**代表用户原文前有「记住：」；**隐式**代表普通用户消息。助手问题不构成用户证据。

| 场景 | 第一批 | 第二批 | 期望保留或退役 |
|---|---|---|---|
| 健身 | 显式：以前在家练背只用哑铃 | 隐式：现在在家锻炼只用弹力带，哑铃已经送人了。显式：我是刚开始练背的新手 | 保留弹力带和新手经验；哑铃退出当前召回 |
| 学习 | 均显式：这学期我在复习英语词汇；以前每次最多 30 分钟；妹妹每次 45 分钟；自己听播客每次 45 分钟；上个月出差那周每次只能 10 分钟 | 隐式：现在每次最多 20 分钟；喜欢用纸质单词卡自测。显式：妹妹的考试是 12 月 8 日。助手猜测：用户是否也在同一天考试 | 保留六个当前事实，分开本人、妹妹和播客；30 分钟旧值与 10 分钟例外退役；助手猜测不入库 |
| 排程 | 显式：我工作日晚上都没有空 | 隐式：我礼拜六上午有空，可以安排活动 | 保留两个不同的可用时段约束 |
| 通勤 | 隐式：上班我通常骑自行车 | 隐式：从家骑车去公司一般要二十分钟 | 分别保留方式和时长 |

## 12 个实时探针

| ID | 用户提问 | 期望证据与评分 |
|---|---|---|
| `equipment` | 我现在有什么器械可以练背？ | 弹力带；不把旧哑铃说成现有器械 |
| `fitness-plan` | 按我现有的器械安排一周背部训练，每周三次，每次45分钟。 | 弹力带 + 新手；三次各 45 分钟，采用弹力带练习，排除哑铃和杠铃 |
| `unknown-gym` | 我办的是哪家健身房的会员卡？ | 空；说明未知或询问 |
| `subject` | 我这学期在复习哪门课？ | 英语词汇；回答英语 |
| `study-plan` | 帮我规划一周英语词汇复习，每周三次，单次时长按我现在的上限，也用我平常的复习方式。 | 当前 20 分钟 + 纸质单词卡；三次各 20 分钟，练习词汇，并体现纸质单词卡 |
| `unknown-exam` | 我的英语考试是几月几号？ | 空；自述无记录或询问，不带出妹妹日期 |
| `availability` | 礼拜六什么时候方便安排活动？ | 周六上午；回答上午或早上 |
| `schedule-plan` | 帮我排一周阅读计划，每周三次，每次30分钟，避开我没空的时段。 | 工作日晚间不可用；三次各 30 分钟，工作日活动不得跨过 18:00 |
| `unrelated-meal` | 豆腐怎么煎才不容易碎？ | 空；正常回答，不夹带排程信息 |
| `commute-mode` | 早上通勤我一般怎么走？ | 骑自行车 |
| `commute-duration` | 早上通勤一般怎么走，大约多久到？ | 骑车和约 20 分钟 |
| `commute-plan` | 我想用平时去公司的方式练耐力，制定一周计划，每周三次，每次30分钟。 | 骑自行车；三次各 30 分钟，用骑行练耐力 |

## 7 个离线学习探针

| ID | 用户提问 | 期望证据 |
|---|---|---|
| `study-limit-paraphrase` | 背新词一轮顶多能花多久？ | 本人词汇上限 20 分钟 |
| `study-limit-old-conflict` | 英语词汇复习现在还要按每次半小时安排吗？ | 本人当前 20 分钟，排除旧 30 分钟 |
| `study-format-paraphrase` | 我习惯拿什么做生词小测？ | 纸质单词卡 |
| `study-sister-duration` | 我妹妹复习英语词汇每次多久？ | 妹妹的 45 分钟 |
| `study-podcast-duration` | 听英语播客一次能安排多久？ | 播客的 45 分钟 |
| `study-sister-exam` | 我妹妹的英语考试是哪天？ | 妹妹的 12 月 8 日 |
| `study-unrelated` | 怎么给米饭保温？ | 空 |

在 `backend` 目录运行 `npm run eval:memory` 可零调用回放当前基线。加 `-- --retrieval-only` 则给两边相同的整理后快照，零调用比较检索。加 `-- --live` 跑完整 **44-call** 比较。完整证据按标注事实 ID 计，干净上下文还要求没有无关记录。无证据题单独统计。回答和计划用固定规则评分，模型不会收到评分标签。见[评测结果](pilot-results.zh-CN.md)。
