## 薄弱点

1. **检索成功后，规划仍会失败。** 健身和通勤未通过时长检查。阅读生成了四次并用了工作日晚间，已被校验拦截。Pilot 只给每题一次规划调用，未评测常规修复的成功率。
2. **文本评分会误判。** 候选的健身房回答“没看到你办卡的具体信息”合理，但规则未识别。基线明确区分了妹妹日期与本人未知日期，却复述了无关的具体日期。应分开评分「承认未知」和「夹带无关事实」。
3. **满分只适用于当前样本。** 额外的零调用探针仍漏掉“报税资料”与“税务文件”的改写，且会混淆“小赵”的时长与本人时长、周末读书与词汇复习。
4. **隐式捕获收益主要来自保留明确原话的规则。** 初次模型提取未新增标注事实。需要把规则可覆盖、模型才可判断、应当跳过三类分开检验。
5. **覆盖面有限。** 四段合成历史、每题一次回答，使用内存 Replay Adapter；没有测真实队列积压、Embedding、Profile/Recap 或专题摘要对真实对话的独立收益，也未做真实流量下的忘记竞态验证。
