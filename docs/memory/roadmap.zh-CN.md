# 心栈中国版 · 记忆下一步

当前已具备显式写入、版本与忘记、两个后台 Job、轻量 Profile/Recap、分域检索和可选 Embedding。44-call Pilot 证明了合成场景内的证据改善，但有效计划只有 1/4。优先补齐「证据找到以后，模型如何可靠地使用它」。

| 优先级 / Anthropic 层 | 下一步实现 | 验收 |
|---|---|---|
| **P0 · Injected Context / Harness** | 把时长、器械、不可用时段转成有来源的结构化约束；当前请求明确覆盖旧偏好。记录初稿、验证、一次修复分别使用的证据。 | 新的留出样本报告初稿与修复后通过率；每个计划能追溯采用了哪些约束，失败不保存。 |
| **P0 · Transcripts** | 可控搜索完整用户证据，补时间过滤、人物 ID、活动范围和证据片段定位；返回「本人」「第三方」「未知」三类归属。 | “报税资料”可找回“税务文件”；小赵、妹妹和跨活动时长不会混入本人计划；忘记后所有检索路径仍为空。 |
| **P1 · Memory Notes** | 将当前规则之外的隐式事实作为独立评测集。核验原话、主体、时效及置信度；弱证据等待确认。记录任务反馈中的用户原话和结果，保留逐版本来源。 | 未知表述、短期例外、模糊纠正和拒绝任务各有正反例；无依据的模型推断不入库。 |
| **P1 · Dreaming** | 用有界预算对易变、冲突、高频事实做定向回看；核验原因与多条来源，并记录其修正前后的效果。看板监测队列滞后、重试、失败和维护 Token。 | 与「只提取」从同一快照对照，减少旧值和重复，同时保持有效事实召回；并发纠正、忘记、重放不破坏状态。 |
| **P2 · Memory Representations** | 选学习或健身一个领域试点带版本引用的专题索引，将 Recap 和 Profile 分别评测。只有稳定、已确认、常用的内容进入每次注入层。 | 同预算比较「只搜」「搜索 + 摘要」「搜索 + Profile/Recap」，检查事实保留、更新时间和成本，再决定扩展范围。 |

先冻结至少一批未参与调规则的中文历史，包括新人物、新任务和跨会话纠正。将来源召回、无关泄露、事实判断、规划通过分开统计，人工复核自由文本误判。Embedding 对比加缓存与失败回退，并以同预算的词法路径作基线。仍以 P0 的记忆生命周期测试作为合并门槛。

分层、后台核验与有选择的上下文注入参考 [Anthropic《The components of agent memory》](https://www.anthropic.com/research/components-of-agent-memory)。优先级和验收条件来自[心栈 Pilot](pilot-results.zh-CN.md)。
